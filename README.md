# 动效术曲skill

面向参考驱动的二维歌词MV制作与局部精修：人物关键姿态、音乐卡点、图形字体、单张／成组风格替换、实机融合、保真封装与同步比较。

## 文件

- `SKILL.md`：与已保存技能同步的规范入口，含YAML名称与触发描述。
- `GUIDE.md`：扩展方法、参数示例与证据局限，执行时按需查阅；不是另一份独立技能入口。
- `QA-CHECKLIST.md`：分阶段验收、证据分级与回滚清单。
- `README.md`：本入口。

## 何时用

用户要做或精修术力口式二维歌词MV，要求卡点、文字设计、风格画张、人物与真实录屏自然衔接，或者要求保留既有设计仅改局部、裁尾、做新旧比较时。

不是“统一降帧”“套全图滤镜”或“把录屏贴进画面”的模板；无需绑定某种模型或平台。

## 开始前准备

1. 最新确认母版、可复用人物／分镜、原音与歌词原文。
2. 已批准／可修改／禁止修改的内容与具体时间范围。
3. 现有对齐证据、原生参考分析、用户实机素材及审片结果。
4. 清楚说明是否裁音、删片头／黑尾，时间原点如何换算。

不要用示例帧率、示例秒数或历史项目切点替代当前输入探测。

优先从`SKILL.md`进入，遇到实现细节查`GUIDE.md`，逐项验收用`QA-CHECKLIST.md`。

## 最短工作流

冻结输入与范围 → 校核音频／分镜 → 用原生邻帧验证参考 → 保护角色与残影 → 少量有动机的图字／姿态／风格替换 → 关键实机短镜与人物互相呼应 → 最小重编码 → 逐帧与音轨QA → 完整成片、原速审片、同段单音轨比较 → 有限精修并保留回滚。

实机优先放在真实中间空档；后部精简为关键操作／信息，人物继续主导。进出要有真实卡框运动与版式承接，不靠极短遮罩掩盖硬弹屏。

## 交付约定

- 完整视频不能被建议或报告替代。
- 联系表来自实际成片解码，标原生帧号；慢放片明确不是成片速度。
- 区分静帧检查、技术解码、音频对齐、动态观看与听审；未做的验证不能宣称通过。
- 未改帧与音轨尽量精确保留；GOP邻接量化、AAC包边界残余及截断尾音如实说明。
- 用户未明确裁音时，不能因黑幕或片长观感自动删去原音。

## 依赖与可移植性

通常需要FFmpeg／ffprobe、图像处理工具、帧表与音频分析工具。先检查本地已有能力；音频对齐工具可替换，不能把某个提供方的认证作为唯一途径。字体、素材和工具各自需有使用权限。

参考链接只用于研究机制，不含官方媒体下载，不授予其画面／角色的使用许可。

## 保存与发布

由负责技能登记的执行者使用`SKILL.md`的名称、description和正文保存；不要把整份带frontmatter文本误当正文。发布前复核目标仓库、可见性与许可证。本包不含项目原片、音频、账号、真实仓库地址或凭据；也不要把执行工作目录一并上传。
